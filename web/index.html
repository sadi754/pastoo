Welcome to Pastoo

Pastoo backs up your folders to your own files.ir account. The first backup uploads everything; after that only what changed goes up. Three steps to start:

  1. On my.files.ir: account settings → Developers → make an API key.
  2. Here, Settings → files.ir: paste the key and press Save key.
  3. Settings → Backup jobs → Add a folder, then come back and press Back up now.
